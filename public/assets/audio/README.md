# Peak interface earcons

All 10 files are original low-amplitude, mono PCM WAV cues (22.05 kHz, 16-bit). These are interface feedback sounds, not music or a continuous ambience track; each has a short fade to prevent clicks.

**Default: muted.** Playback requires explicit user opt-in and must obey browser/system settings. Never autoplay because of price updates, and throttle replay-step sounds during fast replay. Sound cannot be the only notification mechanism. Verify practical loudness, volume adjustment and disable controls before integration.

Replay: step, start, pause, complete. Workspace: click, restore. Studies: save. Attention: price-alert, warning, error.
