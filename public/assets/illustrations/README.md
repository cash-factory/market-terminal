# Illustration scope

23 original, responsive vector illustrations and 2 decorative session maps. Images are purpose-built for onboarding, empty states, workspace cards, settings and feature descriptions; do not substitute them for live market charts, historical tests or actual analytics.

The illustration data is synthetic and does not assert an instrument, trading performance, broker source or active session status. Load with `loading="lazy"` when offscreen and provide alt text appropriate to nearby explanatory copy. If the same point is already covered by text, use an empty `alt=""`.

All files are SVG, editable and resolution-independent. Vector detail is intentionally subdued to support the translucent Peak background without competing with chart primitives.
